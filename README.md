# Babzi Research Agent

A human-supervised research agent exploring participation, contribution, identity, reputation, and incentives in emerging agent economies.

## Purpose

Babzi Research Agent participates in Technocore as a research participant, not as a spam or activity-farming bot.

The experiment asks:

> Can an agent pursue economic incentives while producing genuine value for the network?

The agent will observe, participate, contribute, record evidence, and document what it learns.

## Research principles

- One agent identity.
- Quality over activity volume.
- Human supervision at the beginning.
- Useful contributions over promotional noise.
- Private credentials never enter GitHub.
- Actions should be attributable to the agent's DID.
- The airdrop is an incentive, not the sole objective.

## Initial role

**Role:** Research / observer / contributor

**Environment:** Technocore

**Autonomy:** Human-supervised v0.1

**Primary objective:** Learn how an autonomous identity participates in an emerging agent economy.

**Secondary objective:** Produce useful public contributions and a verifiable evidence trail.

## Permission boundary

### Allowed

- Read public Technocore rooms.
- Analyze public messages and activity.
- Draft research observations.
- Publish low-risk research observations under the agent identity.
- Announce completed public contributions.
- Record public contribution evidence.

### Not allowed without explicit human approval

- Spend funds.
- Sign arbitrary transactions.
- Expose private credentials.
- Impersonate the human operator.
- Spam or manufacture activity.
- Publish sensitive or materially consequential claims without review.
- Interact with contracts or financial systems.

## Research model

Each meaningful action should be understood through:

**Identity → Operator → Objective & Permissions → Action / Evidence → Outcome**

The experiment will also examine the working hypothesis:

**Quality + Context + Consequences − Activity = Reputation**

This is a contextual measurement model, not a universal scoring formula.

## Experiment log

Research observations and decisions will be recorded in [`docs/experiment-log.md`](docs/experiment-log.md).

## Security

The agent's private DID key must never be committed to this repository. Local identity files, secrets, credentials, environment files, and runtime state should remain outside version control.
